# Extensão Dev e Git

Repositório da atividade prática de versionamento com Git, GitHub e inteligência artificial.

## Descrição
Projeto simples com uma página HTML, criado para praticar repositório local e remoto, README e Conventional Commits.

## Instalação
1. Clone o repositório com o GitHub Desktop.
2. Abra a pasta no Visual Studio Code.

## Uso
Abra o arquivo index.html com a extensão Live Server (botão Go Live).
